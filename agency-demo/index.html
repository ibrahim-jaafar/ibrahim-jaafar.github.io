Agency report automation

Every week a marketing agency has to tell each client how their ads did. This workflow pulls the leads, the ad spend and the conversions sent to Meta, checks the data for mistakes in plain code, and writes a short summary a client can read. Two made-up clients: a skin clinic and a home-goods store.

Preview. This page runs the project's tested code (80+ automated tests) in your browser with made-up data. The live version is being connected: an n8n workflow on a free server that uses a GoHighLevel sandbox, Meta's Conversions API with test events, and Gemini for the summary. Nothing you do here is sent anywhere.
