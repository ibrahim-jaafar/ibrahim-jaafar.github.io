How this demo works

A weekly marketing report for two made-up agency clients, a skin clinic and a home-goods store, built as a live n8n workflow: it saves the leads in GoHighLevel, checks the data, sends conversions to Meta, and Gemini writes the summary.

  • Live, end to end: each run saves leads in a GoHighLevel sandbox, sends conversions to Meta, checks the data and asks Gemini for the summary.
  • Checks in plain code: duplicates, missing sources, totals that don’t add up and more are caught by code, not AI.
  • Break it yourself: pick “Choose problems”, run it, and see what the checks catch.
  • AI kept honest: Gemini never types a number. Code fills in every figure.

What’s real and what’s made up

Live: an n8n workflow on a free server. Each run saves the leads and deals in a GoHighLevel sandbox (two sub-accounts), sends the conversions to Meta’s Conversions API (a demo dataset that runs no ads), runs the data checks, and asks Gemini to write the summary. Gemini never types a number: it writes placeholders and the code fills in the real values. If its answer breaks a rule, a template writes the summary instead.

Made up: the two clients, their leads, the ad spend, impressions and clicks, and the mistakes you choose. The demo data can contain mistakes on purpose: that is what the checks are for.
