Agency report automation

Every week a marketing agency has to tell each client how their ads did. This workflow pulls the leads, the ad spend and the conversions sent to Meta, checks the data for mistakes in plain code, and writes a short summary a client can read. Two made-up clients: a skin clinic and a home-goods store.

What’s real here?

Live: an n8n workflow on a free server. Each run saves the leads and deals in a GoHighLevel sandbox (two sub-accounts), sends the conversions to Meta’s Conversions API (a demo dataset that runs no ads), runs the data checks, and asks Gemini to write the summary. Gemini never types a number: it writes placeholders and the code fills in the real values. If its answer breaks a rule, a template writes the summary instead.

Made up: the two clients, their leads, the ad spend and the mistakes you choose. The demo data can contain mistakes on purpose: that is what the checks are for.

The free server sleeps when nobody uses it, so the first run of the day can take a minute to start. One run at a time, at most one a minute.
